# Vue SPA "Список задач"

## Описание проекта

Задачи загружаются из файла tasks.json.

Состояние задач сохраняется в localStorage.

Простое и удобное взаимодействие через чекбоксы.

Структура проекта
src/views/TaskList.vue — отображение списка задач.

src/components/TaskItem.vue — компонент для отображения отдельной задачи.

public/tasks.json — начальный список задач.

## Запуск приложения

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите приложение:

```bash
npm run serve
```

Приложение будет доступно по адресу http://localhost:8080.
